# Omro

Универсальный движок онлайн-каталога контента: фильмы, сериалы, мультфильмы,
мультсериалы, аниме, дорамы, ТВ-шоу (7 типов из коробки). Laravel 12 +
собственный TPL-движок + React-админка.

## Установка на сервер — одна команда

```bash
curl -fsSL https://raw.githubusercontent.com/enikov1/cld/main/install.sh | sudo bash
```

Скрипт сам поставит всё необходимое (PHP-FPM, MariaDB, Node.js, Composer, cron),
скачает движок, создаст базу данных, применит миграции и соберёт интерфейсы.
ZIP-бэкап, найденный в `storage/app/backups/`, будет восстановлен автоматически.

Все параметры установки передаются переменными окружения — это позволяет
запускать установку автоматически из панелей управления сервером.
Для сайтов, уже управляемых панелью (пул PHP-FPM и база есть), используйте
`PANEL_MODE=1` — полный список параметров: `sudo bash install.sh --help`.

После установки пароль базы данных и токен админки сохраняются в
`/root/omro-<SITE_ID>-credentials.txt`.

Админка открывается по пути `/admin/` (токен — `ADMIN_TOKEN`).

## Обновление

**Через админку** — кнопка «Система» в шапке: движок сам проверяет наличие
новой версии на git-хостинге и обновляется по кнопке
(git pull → composer → миграции → сборка → перезагрузка страницы).

**Через SSH:**

```bash
cd /путь/к/установленному/движку && sudo bash update.sh
```

## Шаблоны

- Стандартный шаблон — `resources/tpl/default`: `layout.tpl`, `pages/`,
  `partials/`, `errors/`, `assets/`.
- Свой шаблон — папка `resources/tpl/<имя>` с `layout.tpl`; включается
  в админке. Свои шаблоны не попадают в git.
- Функциональные модули (фильтры, поиск, подписки, избранное, комментарии,
  календарь, плеер) живут в движке (`public/omrotpl/`) и подключаются
  в каждой теме автоматически — привязка к классам темы не нужна,
  используется контракт `data-omro-*`.
- Полная справка по TPL-тегам, контракту omrotpl и переходу с DLE —
  в админке, раздел **TPL-DOC**.

## Разработка локально

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan storage:link
npm install && npm run build:theme
cd admin-ui && npm install && npm run build && cd ..
```

Сборка ассетов после правок: `npm run build:theme` (тема и движок),
`cd admin-ui && npm run build` (админка).
